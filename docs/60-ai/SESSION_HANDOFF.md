# Session Handoff

Güncel kayıt `PROJECT_BOOT.md` içinde tutulur.

- **Session summary:** Bir veya iki cümle.
- **Documents updated:** Değişen kalıcı kaynaklar.
- **Decisions recorded:** ADR veya bağlayıcı kaynak bağlantıları.
- **Remaining risk:** Devamı etkileyen açık risk.
- **Recommended next step:** Tek uygulanabilir adım.

Handoff sohbet dökümü, secret veya kişisel veri içermez.
