# Memory Strategy

## Permanent Sources

- Anayasa ve kabul edilmiş ADR'ler.
- Ürün, mimari, kalite ve operasyon belgeleri.
- `CHANGELOG.md` ve güncel `PROJECT_BOOT.md`.
- Kaynak kod, migration ve test kanıtı.

## Temporary Sources

Sohbet, terminal çıktısı ve scratch notları yalnızca doğrulanıp doğru belgeye
işlendiğinde kalıcıdır.

## Project-specific Retention

- AI handoff kısa tutulur; sohbet özeti veya hassas veri içermez.
- Tarihsel raporlar güncel kaynak olarak kullanılmaz; kod ve CDSK belgeleriyle
  doğrulanır.
- Proje dokümanı retention politikası Git geçmişidir; veri retention politikası `TBD`.
