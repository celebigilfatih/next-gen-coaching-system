# Definition of Done

- [ ] Kabul kriterleri karşılandı.
- [ ] Uygun lint/typecheck/test/build kontrolleri geçti veya gerekçeli engel kaydedildi.
- [ ] Güvenlik, gizlilik ve veri etkileri değerlendirildi.
- [ ] Geriye uyumluluk, migration ve rollback değerlendirildi.
- [ ] İlgili belgeler ve yerel bağlantılar güncellendi.
- [ ] ADR, change request ve changelog gereksinimi tamamlandı.
- [ ] Project Boot ve AI Handoff güncellendi.
- [ ] Açık riskler ve doğrulama kanıtları raporlandı.
