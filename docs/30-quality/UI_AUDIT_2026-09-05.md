## Findings and Fixes

### P2 — Mobile primary navigation order

- **Evidence:** The mobile navigation inherited desktop group order and placed
  Matches before Squad, diverging from the accepted five-task order.
- **Impact:** The same primary navigation changed order between desktop/product
  documentation and mobile.
- **Fix:** Mobile navigation now uses the explicit Week → Trainings → Tactical Board
  → Squad → Matches order from ADR-0011.
- **Post-fix evidence:** Browser accessibility tree confirmed the five links in the
  accepted order at 390 × 844.

### P2 — Drill library phase tabs wrapped on mobile

- **Evidence:** “Cooldown” moved to a second line at 390 px and visually separated
  one phase from the tab group.
- **Impact:** Phase selection looked broken and consumed unnecessary vertical space.
- **Fix:** The mobile tab list now uses five equal-width grid columns with compact
  tab padding and type.
- **Post-fix evidence:** All five tabs share the same y-position and 70 px width;
  document width equals the 390 px viewport.

## Strengths

- The navy/blue/amber visual system and condensed headings remain consistent across
  all routes.
- Primary actions stay in a predictable upper-right position on desktop and become
  full-width actions on mobile where appropriate.
- Empty states explain a useful next step instead of showing blank panels.
- Unknown player position is shown as `TBD`, consistent with CDSK evidence rules.

## Accessibility Risks and Limits

- Captures confirm visible focusable controls, named navigation landmarks, readable
  state labels and absence of horizontal page overflow on the checked mobile screen.
- Screenshots cannot prove full keyboard order, screen-reader announcements, zoom
  behavior, contrast ratios or formal WCAG compliance. The formal target remains
  `TBD` under ADR-0013.
- The local fixture contains no training plan or tactical drill, so populated plan,
  attendance and tactics list density was not re-audited in this pass. Existing E2E
  coverage remains the behavioral source for those states.
